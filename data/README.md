# Reference calculators

Copied from [Steven Liu’s Admix](https://github.com/stevenliuyi/admix), including its demo 23andMe input. The model list and source links below come from the upstream README. The upstream CLI enables 27 models. The supplied K13 files are retained separately because upstream provides no K13 population mapping.

Admix supports many publicly available admixture models. All the calculator files are properties of their authors, and are not covered by the license of this program. Links are provided which contain more information for each model.
